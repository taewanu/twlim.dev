At Lendit, a fintech startup in Seoul, I built internal developer tools. The main one was a VS Code extension for our framework, which renders app screens from component graphs.

## The preview panel

The preview panel renders a component next to its code, in a resizable mobile viewport. Developers could check a component with editable mock data instead of running the app.

## The graph panel

The graph panel shows each component as a directed acyclic graph. Hovering a node highlights what it renders in the preview.

## The roadmap

I led the extension's roadmap as its product owner. I turned feedback from the team's developers into features.

One was a tree view that shows each component's rendered elements as nested directories.

<Clip src="/devtools/graph-tree-highlight.mp4" poster="/devtools/graph-tree-highlight.jpg" width={1100} height={1096} caption="Hovering a row in the tree view highlights its path in the graph." />

## Messages between panels

Each panel runs in isolation. I designed a type-safe message interface with Zod schemas, so panels could post messages to each other through the extension process.

I drew the extension's architecture for its technical guide.

## Documentation

I started the extension's technical documentation. I also built AI prompt files that review docs against writing rules for structure, readability, and Korean usage.

The prompts are enabled across the team's monorepo, to keep docs in one voice.
